# Contributing to AI Game Arena

Community involvement is welcome: issues, ideas, game-adapter proposals, architecture discussions, reproducible experiments and noncommercial forks.

## Before proposing a contribution

1. Open an issue before introducing a major game adapter, protocol change or external dependency.
2. Confirm that you have the right to contribute the material, including employer rights and any source snippets.
3. Identify dependencies and record their exact upstream license, version, notices and redistribution constraints.
4. Do not submit proprietary assets, hidden game APIs, secrets, keys, unlicensed model weights or code copied from repositories without permission.
5. Preserve the essential local/online interface parity invariant and add tests for proposed protocol changes.

## Intellectual property and commercial rights

Contributors retain their own copyrights. The default public licensing intention for original project software is PolyForm Noncommercial 1.0.0 and for original documentation CC BY-NC-SA 4.0.

**Important:** Making a contribution available under those noncommercial licenses does not itself grant the maintainer a right to commercially relicense that contribution. The project needs an explicit separate written grant or contribution agreement if it wants to dual-license substantial external contributions commercially.

No CLA or contribution assignment is currently in force. Maintainers must resolve this before accepting substantial external code intended for a commercially licensed build. In the meantime, discussion and issue reports are the preferred contributions.
